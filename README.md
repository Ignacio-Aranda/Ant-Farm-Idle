# Ant Farm Idle

Un hormiguero en pixel art para dejar puesto en una pantalla. Cada persona de tu
equipo, familia o grupo de amigos es una hormiga: tiene su sala, va al comedor,
cava túneles, celebra su cumpleaños y vive las estaciones y las fiestas del año.

```bash
pip install pygame
python3 hormiguero_pixel.py --ventana
```

Las salas y la gente están en `salas/*.toml`, las fiestas en `calendario.toml` y
el resto de ajustes en `config.toml`.
